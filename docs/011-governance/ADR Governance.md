# ADR Governance

## Purpose

Prevent uncontrolled architecture drift.

---

# Requires ADR

* New database
* New architecture pattern
* New synchronization strategy
* New cryptographic approach
* New storage mechanism
* New dependency

---

# ADR Lifecycle

```text
Proposed
↓
Review
↓
Accepted
↓
Implemented
```

---

# Rule

No architectural change without ADR approval.
